# 1.0.0

## 记录
- 记录增删改查，仅名称必填
- 状态：在用 / 闲置 / 废弃 / 已注销
- 重要度、标签、备注、网址、估值、到期日
- 自定义字段：文本、数字、日期、单选、多选，可限定到某个文件夹
- 文件夹分类，支持图标、颜色、拖动排序，删除文件夹不影响记录

## 登录方式
- 一条记录可挂多个登录方式，标记主登录与可用状态
- 账号可引用身份池，也可直接填写，改名同步生效
- 复用身份池时删除身份，记录自动降级为文本并保留最后的值

## 身份池
- 手机号 / 邮箱 / QQ / 微信 / 其他统一管理
- 查看某个身份被哪些记录引用

## 查找
- 全字段搜索，命中高亮
- 文件夹与状态筛选，五种排序，记住上次选择
- 列表视图与时间轴视图

## 批量
- 多选后批量改状态、移动文件夹、打标签、删除

## 数据
- 导出 zip：records.csv / identities.csv / folders.csv / field_defs.csv / meta.json
- 导入 CSV 或导出包，带预览、冲突策略与导入前快照
- 未知列自动建为自定义字段（文本）
- 回收站：软删除、恢复、清空

## 说明
- 不联网、不加密、不登录，所有数据在本地一个 SQLite 文件里
- 到期日仅应用内提示，不发系统通知
